
# Dev Notes

## Estruturação e Utilização 🔧📓
O projeto Dev Notes é um editor de bloco de notas , utilizando
tecnologias HTML, CSS e JS. Projeto utiltário para salvar anotações com agilidade e praticidade

**Javascript**: Implementar a lógica de CRUD e importação em CSV das notas. Além da manipulação do LocalStorage

**CSS**: Realizar a estilização da página

**HTML**: Realizar a estruturação da página

**LocalStorage**: Garantir a persistência dos dados


## Tecnologias utilizada 💻

**Front-end**:  HTML | CSS | Javascript

## Propósito 🎯

Esse projeto foi proposto com objetivo de consolidar o conhecimento de aplicações utilzando tecnologias base do desenvolvimento web. Utilizado JS Vanilla para analisar cada verificação e lógica para consistência dos dados entre o DOM(Document Object Model) e LocalStorage
